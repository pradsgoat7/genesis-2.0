# GENESIS 2.0 — Opening Sequence

Cinematic 3D intro for **GENESIS 2.0**, QuestIT's hackathon at VESIT (16–17 October 2026).

A heartbeat becomes a single cell that divides into 64 and detonates into a silver moon. An eclipse turns the moon blood red, a slash cracks the screen like glass, and the GENESIS 2.0 lettering burns in.

## Run it

- **Online:** open the GitHub Pages link for this repo.
- **Offline:** download `index.html` and double-click it. Everything (3D engine, fonts, artwork) is inside that one file, so it needs no internet.

Use Chrome or Edge with hardware acceleration on.

## Controls

| Key | Action |
| --- | --- |
| `F` | Fullscreen |
| `H` | Hide / show the controls |
| `R` | Replay from the start |
| `S` or click | Strike (crack, shockwave, lightning) |
| `M` | Sound on / off (restarts with sound) |

The control bar also switches between **16:9** (projector), **9:16** (reels and stories) and **1:1** (feed posts).

## Running it all day

- Set the laptop's screen sleep and screensaver to **Never** and keep the charger in.
- Press `F`, then `H`, and leave it. After the intro the title stays live, with lightning around the moon every few seconds.
